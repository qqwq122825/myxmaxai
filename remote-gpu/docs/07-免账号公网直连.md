# 0.2.0：免账号公网直连

当前推荐方式：本地主动连接租用的 GPU 服务器，用同一个 TLS 加密 TCP 连接上传 / 回传 H.264 视频。无需注册账号、Tailscale、家庭公网 IP 或家庭路由器端口映射。

**使用现有的 4090 服务器即可，不需要再租额外服务器。** 前提是它有可用的公网 IP / 域名，且平台能开放或映射一个 TCP 端口。远程桌面能连接，只能证明远程桌面端口可达；本程序的端口仍需开放。

这是一条专用的视频连接，不是通用 VPN。原 WebRTC / Tailscale 方式保留为可选项。

## 1. 服务器设置

1. 关闭旧版 RemoteGpu，更新到 0.2.0，运行“启动远程端.cmd”。
2. 顶部“连接方式”选 **免账号公网直连**。
3. “服务器公网 IP”填租机平台给出的公网 IP，不含 `http://` 和端口。
4. “服务器监听端口”先填 **8766**。
5. “平台公网端口”通常也填 **8766**；如果平台分配其他公网端口，就填实际映射值。
6. 运行模式先选 **回环测试**，点击“启动当前端”。成功监听后，点击 **复制配对码**。

配对码包括服务器地址、端口、访问密钥和证书指纹，直接粘贴到自己的本地端。它相当于连接凭证，不需要再单独填写账号或密码。

### 端口怎么开

平台映射示例：

```text
服务器公网 IP:8766  →  Windows 虚机:8766 / TCP
```

如果商家公网端口是 24567：

```text
服务器公网 IP:24567 →  Windows 虚机:8766 / TCP
```

此时程序“监听端口”填 8766，“平台公网端口”填 24567。本地使用配对码连接公网端口。

服务器的 Windows 防火墙也要允许本程序的该端口。管理员 PowerShell 在解压目录内执行：

```powershell
.\deploy\开放直连端口.ps1 -Port 8766
```

脚本只给本程序添加指定 TCP 端口规则，不关闭防火墙。平台安全组 / 端口映射仍需在平台配置。本地电脑无需配置入站端口或路由器映射。

## 2. 本地连接

1. 更新到 0.2.0，运行“启动本地端.cmd”。
2. 顶部选择 **免账号公网直连**，粘贴服务器复制的配对码。
3. 第一轮选“测试图”或“YY开播”，分辨率先用 720p。
4. 第一轮先取消“输出到 FaceLive Camera”，只验证回传预览。
5. 点击“启动当前端”。界面应出现回传画面及 FPS / 上下行码率。

回环通过后，按原桥接流程安装远程输入摄像头并连接 Pro 2.7：

```text
本地 YY → 加密 TCP → 远程 FaceLive Camera #2
        → DeepLiveCam Pro 2.7 → 结果摄像头
        → 同一加密 TCP 连接回传 → 本地 FaceLive Camera → 直播伴侣
```

配对码在远程同一用户下可重复使用。服务器地址 / 公网端口变化后重新复制即可；换电脑或删除服务器身份文件后，证书与密钥会变化，需要重新配对。

## 3. 加密与认证方式

服务器首次自动生成 TLS 证书与随机长密钥。配对码带有该证书的 SHA-256 指纹；本地必须验证匹配后才发送密钥和打开摄像头，不关闭 TLS 校验，也不要求用户向 Windows 导入根证书。

证书、私钥和随机密钥保存在服务器当前用户的 `%LOCALAPPDATA%\FaceLiveRemoteGpu\direct-identity`，不放进发布包。配对码不写入普通日志，也不作为 URL 查询参数发送。

程序同时只接受一个视频会话，错误配对密钥被拒绝；证书不匹配会在打开本地摄像头前停止。原始帧队列只保留最新帧，发送长时间阻塞或接收延迟持续累积时断开，避免补播很久以前的画面。

## 4. 性能边界

- 本版仍是软件 H.264 编解码，最多 720p / 30 FPS。4090 用于第三方换脸软件的推理，NVENC 媒体发送尚未启用。
- TCP 让部署只需一个端口，但丢包时重传会影响后续帧。公网延迟、丢包和吞吐必须实测，不能用本机回环性能代替。
- 本版不提供自动重连、音频传输或音频延迟模块；断流会切黑并停止当前连接。
- 配对与连接已经不依赖 Tailscale；现有的 Tailscale 不需要为了运行本程序重新登录。

## 5. 自检与命令行

```powershell
python remote_gpu.py direct-selftest --seconds 6
python remote_gpu.py direct-selftest --camera yy --portrait --seconds 6
```

以上都仅在本机跑 TLS 视频往返，不访问远程 GPU。真实 YY 测试前应停止其他 RemoteGpu 预览，避免输入设备被占用。

服务器命令行示例（替换为自己的 IP）：

```powershell
python remote_gpu.py direct-agent --public-host 203.0.113.10 --port 8766 --public-port 8766
```

成功监听后会生成 `server.pairing`，本地可使用：

```powershell
python remote_gpu.py direct-client --pairing-file server.pairing --camera yy --portrait --sink none
```

图形界面用户只需要复制 / 粘贴配对码。

没有旧版完整目录时，请使用完整包。不要只复制 EXE 到空目录；它依赖 `_internal` 中的运行库。
