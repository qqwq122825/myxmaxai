# 独立视频摄像头测试

双击 `VideoCameraTest.exe`，无需启动本地端、服务器端，也无需安装 Python。

1. 点击“添加视频”，选择 MP4、MOV、MKV、AVI 等本地素材。窗口显示首帧预览。
2. 选择横屏或竖屏、720P 或 1080P。画面等比缩放，空余区域补黑。
3. 点击“启动虚拟摄像头”。首次使用会请求管理员权限，安装独立的测试摄像头驱动。
4. 在 OBS、直播伴侣或支持 DirectShow 的软件里，选择 **Sony ZV-E10**。
5. 素材按自身帧率播放，结尾自动从头循环；窗口显示已循环次数。
6. 点击“关闭虚拟摄像头”停止播放并释放输出；关闭窗口也会停止。再次启动从素材开头播放。

`Sony ZV-E10` 是本测试工具的虚拟设备显示名称。仅输出视频，不输出素材音频。
设备安装后保留在摄像头列表中；“关闭”停止画面输出，不卸载设备。
首次安装后，如果目标软件未刷新设备列表，请重开目标软件。Windows 相机等仅使用 Media Foundation 的应用可能不显示此 DirectShow 设备。

测试驱动使用独立的设备标识、共享内存和分辨率配置，不占用现有的 FaceLive Camera、Camera #2 或 Camera #3。
驱动安装到 `%ProgramData%\FaceLive\VideoTest`，不会依赖运行时的临时解压目录。
安装失败详情保存在 `%LOCALAPPDATA%\FaceLiveVideoTest\install-error.txt`。

本地构建（已具备项目 Python 依赖、PyInstaller、VS C++ Build Tools）：

```powershell
.\remote-gpu\deploy\build-video-test.ps1 -Python .\.build\remote-live-venv\Scripts\python.exe
```

输出：`dist\VideoCameraTest\VideoCameraTest.exe`。EXE 自带运行库与两种位数的驱动，可单独运行。
