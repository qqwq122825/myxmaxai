## 0.2.0：免账号单端口直连

用户已确认平台可以开放 / 映射自定义 TCP 端口，因此增加无需 Tailscale 的专用 TLS 视频连接。以下仍是本机测试结果：

- 35 项自动化测试通过，包括原功能与新增真实 H.264 编解码、TLS 双向视频、证书指纹验证、错误密钥拒绝、忙会话拒绝和资源释放。
- 1280×720 合成图，单端口 TLS 回环：210 帧 / 7.01 秒，统计平均 30.0 FPS。
- 真实 YY 输入，720×1280，单端口 TLS 回环：191 帧 / 7.08 秒，统计平均 27.31 FPS；同一台本机承担两端编解码。
- 首次 YY 测试遇到输入设备占用；关闭此前打开的旧版本地预览后通过。原 YY 软件保持运行。
- 该连接无需账号、STUN、TURN 或额外组网服务；服务器证书与随机密钥由程序本机生成。

公网 4090 两机传输、平台端口映射与换脸软件仍待实际部署后验证；不能把上述本机 FPS 当成公网或换脸性能。

- 0.2.0 打包 EXE 的真实 YY 单端口回环通过：720×1280，192 帧 / 7.06 秒，统计平均 27.45 FPS；停止后会话释放。
- 打包 EXE 从 `C:\Windows\System32` 作为工作目录启动 GUI 的检查通过，界面版本为 0.2.0，不依赖启动目录可写。
