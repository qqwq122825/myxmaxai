# 0.3.1：地址 + 一个 Key

两台电脑都更新到 0.3.1。本地只填服务器地址和一个 Key，不再填写配对码或证书指纹。

## 服务器

1. 运行 `RemoteGpuServer.exe`。
2. 确认平台给出的公网 IP、监听端口和公网端口，默认 TCP 8766。
3. 点击“复制 Key”。Key 在程序启动后自动准备，不依赖公网 IP 检测成功，也不必先启动监听才能复制。
4. 点击“启动接收”。平台映射和 Windows 入站规则仍需允许该 TCP 端口。

## 本地

1. 运行 `RemoteGpuLocal.exe`。
2. “服务器地址”填写 `公网IP:公网端口`；省略端口时默认 8766，也支持 `https://公网IP:端口`。
3. 将服务器复制的 Key 粘贴到“连接 Key”，或点击“粘贴 Key”读取本地剪贴板。可以直接在输入框 Ctrl+V，不必点击导入。
4. 选择本地摄像头 / YY，点击“启动推送”。

服务器 Key 以 `RGK1.` 开头，直接复制完整内容即可。同一台服务器会保持同一个 Key；只修改地址或端口不需要重新生成 Key。换机器、重建服务器身份后使用新 Key。旧版只有原始密钥的 Key 需在新版服务器重新复制一次。

服务器收到画面后，按原流程提供 Camera #2 给换脸软件，选择结果窗口并“预览结果”，再“开始回传”。本地开启 FaceLive Camera 给直播伴侣。等待回传时本地原画持续上传。

## 兼容与验证

新版 Key 将访问凭据和服务器身份合在同一个字符串中；程序自动校验 TLS 身份，不需要用户另外操作证书，也没有关闭证书验证。网络认证依然使用原来的服务器访问凭据，因此不会因为 Key 的显示方式变化而重建服务器身份。

“粘贴 Key”也接受旧版完整 RGPU1 配置并自动转换，便于已有剪贴板内容继续使用；新界面不再要求复制它。旧式命令行配对文件仍保留兼容，常规图形界面只用地址和 Key。

从完整 0.3.0 升级：先退出旧程序，将 `RemoteGpu-0.3.0-to-0.3.1-update.zip` 中的 `RemoteGpu` 文件夹合并覆盖原目录，保留原 `_internal` 中的其余文件。两台电脑都要更新，再分别运行各自入口。
