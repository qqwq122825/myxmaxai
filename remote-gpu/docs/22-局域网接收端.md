# FaceLive LAN 1.0.3 · Windows 局域网接收端

与手机 AI魔颜 的「局域网 Wi-Fi」模式配套。手机和电脑在同一路由器下，视频直接传到电脑，不经过远程 GPU 服务器。手机麦克风可以单独从电脑默认音响播放。

## 使用

1. 运行 **FaceLiveLan.exe**，自动启动接收并显示二维码，无需安装 Python 或填写 IP、端口、Key。
2. 手机和电脑连接同一路由器，用 AI魔颜 → 局域网 Wi-Fi → 扫码。也支持系统相机扫码打开 App。首次使用允许手机 App 的「本地网络」权限；Windows 弹出网络访问提示时，允许接收端使用可信的专用网络。
3. 手机画面自动显示在右侧预览。左侧显示二维码、摄像头启停按钮和麦克风监听开关。
4. 点 **启动虚拟摄像头**。首次启动自动注册名称固定为 **xxx3** 的摄像头；如出现 Windows 管理员授权，请确认。之后直接启停。
5. 在换脸软件或直播伴侣里选择 **xxx3**。首次注册后，已打开的目标软件可能需要刷新设备列表。

使用麦克风需要安装含此功能的新版 AI魔颜。手机扫码连接后允许麦克风权限，再在电脑勾选 **监听手机麦克风**。监听默认关闭，取消勾选立即静音。如果直播软件需要收录手机声音，请将系统播放设备加入直播音源。关闭接收端的监听也会切断这路播放音源。

xxx3 使用独立设备标识、共享内存和配置，不占用原 FaceLive Camera、Camera #2、Camera #3 或 Sony ZV-E10。驱动按版本放在 `%ProgramData%\FaceLive\LanCamera`，不会覆盖其他软件正在使用的 FaceLive DLL。

摄像头输出跟随手机实际尺寸，支持 720P／1080P 横竖屏、最高 30 FPS。切换手机分辨率重新连接后，输出会重新创建；读取它的第三方软件可能需要重新打开摄像头。手机局域网模式目标码率：720P 6000 Kbps、1080P 12000 Kbps。

摄像头关闭后，手机预览和接收继续；关闭软件才停止接收服务。手机停止推流或断线后，预览和摄像头清黑；手机重连无需重启 EXE。一个接收端同一时间只接一台手机。

内网地址自动识别，每 10 秒检查网络变化、更新二维码；未连接局域网时会等待连接。默认端口 8767，如已被占用，会自动选择附近空闲端口并写入二维码。

## 配置与诊断

- 身份和配置：`%LOCALAPPDATA%\FaceLiveLan`。Key 和二维码含连接凭证，应用不会上传它们。
- 无需账号，沿用此电脑已生成的 Key。
- 安装／防火墙报告：`%LOCALAPPDATA%\FaceLiveLan\reports`；xxx3 安装详情为 `camera-install.json`。取消管理员授权后可以重新点击启动。
- 仅用本机回环验证手机协议（不读物理摄像头、不改驱动、不设置防火墙）：

```powershell
.\FaceLiveLan.exe --selftest --report "$env:TEMP\facelive-lan-check.json"
```

自检确认 TLS、鉴权、1080P 解码、麦克风包接收及监听启停、重复连接拒绝、心跳、断线重连。真实 iPhone 相机推送、路由器和目标软件的画面仍需在对应设备上验证。

## 从源码构建

```powershell
.\remote-gpu\deploy\build-lan.ps1 -Python .\.build\remote-live-venv\Scripts\python.exe
```

输出 `remote-gpu/dist/FaceLiveLan-1.0.3/FaceLiveLan.exe`。运行 EXE 时无需旁边的 Python／DLL 文件，驱动已内嵌；分发时保留同目录许可证和说明。构建需要 VS C++ Build Tools；只构建 LAN 专用的 32／64 位驱动，不安装驱动。
