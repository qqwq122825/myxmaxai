# 0.4.5 本地控制与滚动条

- 本地端左侧底部固定显示「启动虚拟摄像头」「关闭虚拟摄像头」两个独立按钮，不会随表单滚走。
- 未启动时仅可启动；运行时仅可关闭。重复调用启动或关闭不会反向切换状态。
- 摄像头开关独立于网络接收，关闭摄像头仍可继续接收服务器结果。
- 镜像、输出检查及摄像头状态也放在固定控制区。直播伴侣中只保留一路 FaceLive Camera。
- 左侧改为无箭头的浅色圆头细滚动条，支持拖动和点击定位；无需滚动时隐藏滑块。
- 鼠标在左侧输入框、下拉框、文字区域上也能滚动表单；滚轮不会误改下拉框的选择。下拉弹出列表仍使用自己的滚动。
- 不再因为已安装驱动与包内 DLL 哈希不同就禁止启动。用户已确认旧设备能够工作，重复素材占用是这次直播伴侣不可选的原因；驱动差异仅记录日志。

已有完整 0.4.4 时，关闭旧桥接端，将增量包中的 RemoteGpu 合并覆盖，重新运行 RemoteGpuLocal.exe 即可。此次界面更新不需要重新注册驱动。

此次只修改桥接端，没有修改 DeepFaceLive、手机 App 或直播伴侣。
