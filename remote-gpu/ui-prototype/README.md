# 独立双端 UI 原型 · 第 2 稿

本目录保留早期设计稿。实际程序 0.3.1 已进一步简化为“服务器地址 + 一个 Key”，去掉配对码与手填证书；当前操作以 `docs/09-地址与单Key连接.md` 为准。

浏览器打开 `index.html` 查看目录；`client.html` 与 `server.html` 是两个独立界面，没有运行端切换，表单状态不共享。CSS 和演示脚本为共用设计资源，不代表两个运行端共用配置。

本地端：点击“导入配置”填入示例 → “启动推送” → “模拟结果回传”。“开启虚拟摄像头”单独控制。

服务器端：点击“识别 IP”填入示例 → “复制连接配置” → “启动接收” → “模拟本地接入” → 选择结果窗口 → “预览结果” → “开始回传”。也可选择结果虚拟摄像头，或用原画回环测试网络。

本稿所有操作均为模拟，不会读取剪贴板、枚举真实窗口、请求摄像头权限、检测公网 IP 或建立网络连接。复制按钮仅复制不可连接的演示配置。

待确认后实现：独立双端入口与配置、公网地址检测（允许平台地址覆盖）、Key / TLS 身份提前准备、窗口结果采集、独立启停接收与回传、虚拟摄像头开关。窗口最小化、关闭、变更尺寸与裁切行为需在真实软件上验证。

连接安全：连接配置仍包含 TLS 证书校验信息；“地址 + Key”界面不会意味着关闭服务器身份验证。检测得到的公网出口 IP 不能代替平台公网入口与端口映射的核对。Key 和配对配置不可公开分享。
