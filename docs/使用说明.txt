换脸直播助手（自用版）
==========================

一、第一次使用
1. 解压整个文件夹到固定位置（比如 D:\FaceLive），双击 FaceLive.exe。
   - 如果打不开、提示缺少 MSVCP140.dll / VCRUNTIME140.dll：
     安装微软官方「Visual C++ 2015-2022 x64 运行库」（搜索 vc_redist.x64.exe）。
   - Windows 可能弹出“已保护你的电脑”：点“更多信息”→“仍要运行”（程序没有做数字签名）。
2. 左侧填入 API Key（Xmax 后台 API Keys 页面创建，uk- 开头），
   账号在 platform.xmax.ai 注册的选「国际版」。
3. 选择“采集后端”和“采集设备”，右下角会出现原始画面预览（预览不收费）。
   - 使用 YY 开播画面：先打开 YY 开播并设置好画面，再选择 DirectShow → YY开播。
   - 使用真实摄像头：在 DirectShow 或 Media Foundation 下选择对应设备。
   - “YY开播”是虚拟摄像头设备名，不需要选择 YYAnchor 进程。
   - YY 的输入分辨率由本程序顶部“输出画布”手动选择，横竖屏不会自动切换。
   - 选择竖屏时会向 YY 请求相同的竖屏尺寸；像素格式由设备自动协商。
   - 不要在 YY 中再添加本程序的 FaceLive Camera，避免画面循环。
4. 分辨率选择位于主界面顶部“输出画布”，始终可见：
   抖音竖屏直播选「竖屏 720×1280」或「竖屏 1080×1920」。
   “填满画布”按比例放大并裁剪边缘；“完整画面”保留全部内容，比例不同时会有黑边。
   原始画面与生成画面并排预览，预览画布随所选横竖屏比例变化。
5. 看不清生成效果时：点击“生成画面”右上角的“大屏预览”，双击生成画面，或按 F10。
   独立窗口默认最大化，可拖到另一块屏幕、调整大小或置顶。
   双击画面或按 F11 全屏，Esc 退出全屏；大屏右上角可直接停止生成。
   关闭大屏不会停止生成；打开大屏不会新建生成会话。
6. 采集设备下方的“生成画质”默认选择“最高画质 · 固定最高档”：
   上传和接收均从最高档开始，关闭 SDK 自动降档，并优先保留画质。
   要请求竖屏 1080p，请同时在顶部选择 1080×1920；横屏选择 1920×1080。
   网络不稳定时可停止生成，再改为“自适应 · 网络优先”。
   生成画面下方分别显示实际生成尺寸和输出画布尺寸；若输出经过放大会明确标注。
   最高档表示请求策略，服务端实际返回尺寸仍以实测为准。

二、开播
1. 选效果（换人物 / 换衣服 / 换风格）和一张参考图，或者上传自己的图片。
2. 点「启动虚拟摄像头」。第一次会弹出管理员授权（安装虚拟摄像头驱动），点“是”，以后不再弹。
   从这一刻开始按 1 积分/秒计费，右下角显示时长和消耗。
3. 打开直播伴侣 → 添加素材 → 摄像头 → 选择「FaceLive Camera」。
   （如果安装虚拟摄像头时直播伴侣已经开着，要先重启直播伴侣才能看到。）
4. 直播中点别的参考图可以直接切换形象，不用停。
5. 下播一定要点「停止虚拟摄像头」或直接关掉程序，否则会一直计费。
   高级设置里可以设“自动停止 N 分钟”防止忘关。

三、常见问题
- 直播伴侣里画面倒过来了：高级设置里切换「上下翻转修正」。
- 左右方向：在“采集设备”下方切换「左右镜像 · 预览与生成一致」。
  默认开启，沿用手机自拍式预览方向，同时把相同方向的画面发送给生成服务。
  关闭后与 YY 输出的原始方向一致。生成画面和虚拟摄像头不再额外翻转。
  修改镜像前请先停止生成；不要只看自拍预览来判断最终输出方向。
- 直播伴侣显示黑屏：还没点「启动虚拟摄像头」时虚拟摄像头输出黑画面，属于正常；点开始后就会出画面。
- 直播伴侣里出现彩色条纹 + 英文提示：说明本程序没开着，打开本程序即可。
- 画面卡顿/模糊：网络不好时 SDK 会自动降画质，检查网络或关掉代理/VPN。
- 改了输出分辨率：直播伴侣里把这个摄像头删掉重新添加一次才会生效。
- 不想要虚拟摄像头了：程序里点「卸载」。

四、合规提醒
- 只用本人、自有或已获授权的形象，不要冒充真实的他人。
- 抖音等平台要求对 AI 生成内容进行标识，请按平台规则在直播间声明。

五、数据位置
- 设置（API Key 已用 Windows 加密保存）：%AppData%\FaceLive\settings.json
- 虚拟摄像头驱动：C:\ProgramData\FaceLive\VirtualCam
- 虚拟摄像头基于开源项目 UnityCapture（MIT 协议），换脸能力来自 Xmax SDK（MIT 协议），
  许可证见 VirtualCam 文件夹。
